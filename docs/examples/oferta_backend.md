# Ingeniero/a de software backend — Python

Buscamos un perfil intermedio para desarrollar servicios de una plataforma de
reservas. El equipo trabaja con Python, FastAPI, PostgreSQL, Docker y Git.

## Responsabilidades

- Diseñar APIs REST y mantener integraciones con otros servicios.
- Modelar datos, escribir consultas y mejorar el rendimiento de PostgreSQL.
- Prevenir reservas duplicadas en situaciones de alta concurrencia.
- Escribir pruebas y participar en revisiones de código.
- Investigar incidentes con logs, métricas y trazas.

## Requisitos

- Fundamentos de Python, HTTP, SQL y transacciones.
- Experiencia razonando sobre concurrencia, idempotencia y manejo de errores.
- Capacidad para comunicar decisiones y sus ventajas e inconvenientes.

## Temas para la entrevista

Explorar diseño de una API de reservas, consistencia de datos, pruebas de casos
límite y un ejemplo de colaboración para resolver un incidente técnico.
